# Visual Review Skill

## Purpose

Evaluate a rendered website and identify changes that will most improve its visual quality and usability.

Never assume the first generated composition is acceptable.

## Inputs

Review rendered screenshots at representative widths, preferably large desktop, laptop or tablet, and mobile. Also inspect the live page when browser interaction is available.

## Review Order

### 1. Overall impression

Determine whether the page appears intentional, coherent, distinctive and appropriate for the organisation. If the page feels like a generic template, identify why.

### 2. Visual hierarchy

Check whether the eye naturally reaches the most important information first. Assess heading scale, contrast, visual weight, image prominence, CTA prominence and information density.

### 3. Typography

Inspect font pairing, line length, heading proportions, line height, paragraph density, consistency and excessive font sizes.

### 4. Layout and spacing

Look for inconsistent margins, arbitrary gaps, cramped areas, excessive empty space, alignment problems and overly uniform sections.

### 5. Section rhythm

Successive sections should not all use the same visual structure. Look for repetitive patterns such as heading + paragraph + three cards, centred heading followed by identical grid, or alternating generic feature blocks. Variation should be purposeful rather than random.

### 6. Components

Check whether components are being overused, especially cards, pills, badges, buttons, bordered containers and rounded boxes. Ask whether each container actually needs to be visually enclosed.

### 7. Imagery

Images should contribute to the composition. Check crop, scale, relevance, focal point, aspect ratio, repetition and interaction with surrounding typography.

### 8. Responsive behaviour

Mobile should be recomposed rather than merely collapsed. Inspect reading order, navigation, text size, line length, image crop, CTA placement, spacing, overflow and touch targets.

## Generic AI Design Warning Signs

Flag unnecessary use of purple or blue gradients, glass effects, glowing backgrounds, floating decorative shapes, pill-shaped labels above every heading, excessive rounded cards, three-column feature grids, generic icon circles, meaningless statistics, oversized hero text and repetitive centred layouts.

These patterns are not forbidden. They require a design justification.

## Refinement Procedure

1. Identify the three most important weaknesses.
2. Explain why each weakens the page.
3. Make targeted changes.
4. Render again.
5. Compare the revised result with the previous version.
6. Repeat if major problems remain.

Do not respond to every weakness by adding decoration. Prefer improving hierarchy, proportion, spacing, composition, typography and imagery before adding visual effects.

## Completion Standard

The review passes when hierarchy is immediately understandable, the design feels appropriate to its subject, typography and spacing are coherent, desktop and mobile both feel intentionally composed, repeated components do not dominate the design, no obvious generic AI aesthetic is present, and no major visual defect remains.
