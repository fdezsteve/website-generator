# ADR 003 — Render, Review, Refine

## Status
Accepted

## Decision

Rendered visual inspection is a mandatory stage of generation, not an optional QA step.

Substantial pages must be rendered at representative viewport sizes, inspected visually, and refined before completion.

## Consequences

- code correctness alone cannot define completion
- visual quality problems are surfaced earlier
- generic AI-generated patterns can be identified and removed
- mobile and desktop composition are reviewed as designed experiences
