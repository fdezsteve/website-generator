# Alder & Lane — Site Plan

## Site objective
Turn interest into an in-person visit by combining immediate practical information with a compelling sense of food and place.

## Priority audiences
Nearby residents need hours, location and a reason to make the café habitual. Weekend visitors need food, atmosphere and menu confidence. Local workers need fast lunch/hours/location retrieval.

## Primary journeys
- Discover café → experience food/place → inspect highlights → check visit details → visit.
- Arrive with intent → open Menu → scan relevant category/dietary information → check Visit.
- Arrive for logistics → see hours/location immediately → open Visit for detail.

## Sitemap

### Home
Purpose: establish character quickly and make visiting feel desirable and easy.
Primary action: See the menu.
Major content: identity/positioning; immediate open-hours/location utility; immersive food/place introduction; selected seasonal menu highlights; photographic atmosphere; concise food/coffee proposition; visit handoff.

### Menu
Purpose: make the current offering pleasurable and fast to explore.
Primary action: Plan your visit.
Major content: breakfast; lunch; pastries; coffee; non-alcoholic drinks; dietary indicators; contextual food imagery. Avoid turning every dish into a card.

### Visit
Purpose: remove practical friction before arrival.
Primary action: Get directions/location handoff when real map data exists.
Major content: address; opening hours; transport/parking; accessibility; contact details; location treatment; one strong exterior/interior orientation image.

## Navigation model
Primary navigation: Home, Menu, Visit. Café name/mark returns Home. Mobile uses an accessible compact menu only if all three destinations cannot remain comfortably visible; do not hide them by default merely to imitate common mobile navigation.

Footer: repeat address/hours/contact when supplied, plus essential legal/credit links only if needed.

## Content hierarchy
Home primary: identity, food/place imagery, hours/location, menu route. Supporting: selected dishes, coffee/food character, atmosphere. Optional: subtle seasonal cue if backed by content.

Menu primary: category, dish name/description/price when data exists. Supporting: dietary indicators and imagery. Optional: ingredient/source notes only if supplied.

Visit primary: address, hours, directions/location. Supporting: transport, parking, accessibility, contact. Optional: orientation imagery.

## CTA discipline
Use text links and direct navigation where a button would add visual noise. “See the menu” is Home's primary CTA. “Plan your visit” connects Menu to Visit. Visit should favour functional direction/contact actions rather than a decorative CTA banner.

## Trust
Real photography, transparent menu/prices, clear hours/location and useful accessibility information are the trust mechanisms. No testimonials, awards, star ratings or statistics.

## Release scope
All three pages are essential. No secondary pages are currently justified.

## Assumptions
Missing operational details will use clearly marked fictional benchmark data during implementation. Actual external map/directions behaviour waits for an explicit test address or real client data.
